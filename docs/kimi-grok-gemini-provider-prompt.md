## What exists today

The Claude-provider milestone made "provider" a first-class seam. A provider = a runner script in the sandbox image + a credential-holding gateway route, never a chat-API integration:

- `lib/provider-credentials.ts:5` — `CREDENTIAL_PROVIDERS = ["anthropic", "openai"]`, `providerLabel` (two-way ternary), `DEFAULT_PROVIDER_MODELS`, `resolveRunModel`, `resolveRunCredentialSource` (owner-else-server-else-refuse).
- `scripts/claude-runner.mjs` — Claude Agent SDK runner. **Already fully parametrized by `OPENFLOOR_ANTHROPIC_BASE_URL`/`OPENFLOOR_ANTHROPIC_TOKEN`**: it never contacts Anthropic directly, only the gateway. `scripts/codex-runner.mjs` is the Codex equivalent.
- `app/runtime/anthropic/[...path]/route.ts` — the gateway pattern: run-scoped JWT (`verifyRunGatewayToken`, operation-bound), run-status check, 10 MiB cap, path allowlist Set grown from observed traffic (log-then-404), owner-key-else-server-key-else-503 via `resolveRunCredentialSource` + `decryptCredential`, upstream fetch with SSE body passthrough.
- `worker/agent-run-workflow.ts` — provider branches at :151 (CLAUDE.md prompt append), :173 (non-root `openfloor-agent` prep + `~/.claude/settings.json` + skills), :227 (`runuser` start command), :230 (providerEnv). `RUN_SANDBOX_IMAGE_VERSION = "v2"` at :66.
- `lib/agent-run-start.ts:47` — `disabledRunProviders()` reads `CLAUDE_RUN_ENABLED`; consumed by the manual-start seam, `db/routing.ts` per-item skip (:160, :227), and agent creation (`app/api/sessions/[id]/agents/route.ts:18`).
- `db/schema.ts:204, :698` — `provider` columns are **TS-only open enums, no SQL CHECK — adding providers requires NO migration**.
- Claude's isolation posture: microVM outside + `srt` (bubblewrap, proxy-enforced domain allowlist = `[gatewayHost]`) inside, as non-root `openfloor-agent`, pinned by `lib/claude-sandbox-settings.ts`. Codex's is the Codex CLI's own kernel sandbox (`sandboxMode: "workspace-write"`, `networkAccessEnabled: false`).

**The key architectural fact this plan exploits: any vendor with an Anthropic-Messages-compatible endpoint can reuse `claude-runner.mjs` with zero runner changes — only a new gateway route with a different upstream is needed.** Kimi and Grok are that case. Gemini is not, and needs a new runner.
